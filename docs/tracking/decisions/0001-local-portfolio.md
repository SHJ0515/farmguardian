# 로컬 재현과 성능 비교를 포트폴리오의 목표로 삼는다

## 배경과 결정

기존 계획은 실제 production 운영까지 포함했지만, 사용자는 2026-10-22 취업용 포트폴리오와 향후 기능 개선 사례를 목표로 확정했다. 실제 서비스 운영은 계획하지 않으며 로컬 기능·성능 시험은 가능해야 한다. 데모 규모·부하 수치·개선 주제는 측정 준비 과정에서 정한다.

## 대안과 결과

- 실제 운영 출시까지 필수로 두는 대안은 운영 인프라·계정·배포 대응이 필요하지만 현재 사용 목적에 포함되지 않아 채택하지 않았다.
- 코드 설명과 화면만 준비하는 대안은 실제 구현·성능 시험 요구를 충족하지 못한다.
- CI·컨테이너·관측성은 로컬 재현에 기여할 때 선택한다. 측정하지 않은 부하 보장이나 운영 안전성 완료를 포트폴리오 성과로 주장할 수 없다. 로컬 용도도 타 사용자 접근·비밀값 노출을 허용하는 근거는 아니다.
