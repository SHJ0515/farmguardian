# 공급 장치를 계정별로 등록하고 현재 소유자는 하나로 둔다

## 배경과 결정

서비스가 연동할 장치는 운영진에게서 렌탈하거나 구매하는 IoT 장치다. 한 계정에 여러 물리 장치를 허용하고, 각 장치의 현재 소유 계정은 하나로 제한한다. 농장 구성원끼리 공유하는 기능은 계획하지 않았다. 시리얼 번호 등 공급 장치의 식별자를 사용한 등록 흐름을 지향하며 직접 촬영용 가상 장치는 물리 장치와 구분한다.

## 대안과 결과

- 계정당 물리 장치 1대 제한은 사용자의 다중 등록 요구와 맞지 않아 채택하지 않았다.
- 외부 임의 구매 장치의 개방 연동, 농장 단위 공동 소유는 현재 공급·사용 범위에 없으므로 별도 요구 없이 추가하지 않는다.
- 식별자만으로 실물 보유가 증명되지는 않는다. 등록 증명·동시 선점·반납/재할당·과거 사진 보호는 별도 설계가 필요하다. 공급 방식에서 결제·렌탈 계약 시스템의 구현 요구를 추론하지 않는다.
