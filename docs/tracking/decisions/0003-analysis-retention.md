# 외부 실패와 사진·분석 결과의 보존을 분리한다

## 배경과 결정

분석기 호출이나 푸시 전달은 실패할 수 있다. 사용자는 나중에 앱을 열어 사진과 이미 얻은 분석 결과를 확인할 수 있어야 한다고 확정했다. 분석 전 저장한 사진 메타데이터는 분석 실패 후에도 남기고, 분석 결과를 저장한 뒤 발생한 푸시 실패도 결과를 취소하지 않는다.

## 대안과 결과

- 저장·분석·알림을 모두 성공해야 유지하는 단일 원자적 처리 방식은 외부 장애 때 사진/결과를 잃으므로 요구에 맞지 않는다.
- 사진 저장, 외부 분석, 결과 저장, 알림 시도가 나뉘어 부분 성공이 존재한다. 실패 상태 표시·안전한 재처리·중복 요청 처리가 후속 과제가 된다.
- 이 결정은 외부 저장소 원본의 영구 보존이나 무제한 자동 재시도를 뜻하지 않는다. 보존 기간과 재처리 정책은 미정이다.
