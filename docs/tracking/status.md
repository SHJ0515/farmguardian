- 신뢰도 상향의 정확한 수치·경계·평가 자료, 야간 제한 재활성화의 시간대와 경계는 미정이다. 야간 검사는 지금은 끄고 19~06시 의도를 유지한다.
- 사진 과거 owner 근거·격리/삭제, assignment 이력 필요성, 탈퇴 보존 기간, 이메일 정규화·재사용, FCM 다른 계정 이전/거부 정책은 미정이다.
- Access 즉시 폐기, 로그인 실패 통일, 관리자 Page JSON·잘못된 size/sort 처리·DB 검사 실패 응답, 새 감사 방식·보존 기간은 기존 보류를 유지한다.
- 관리자는 수동 지정·JWT와 DB의 ADMIN/미탈퇴 동시 검사, 장치 목록 20개 고정·ID ASC, 개별 알림 기존 계약 유지 방향이 확정됐지만 구현·개방은 아직 안 됐다. broadcast는 별도 개방 보류다.
- `INACTIVE` 전이, 시리얼과 현재 UUID의 관계, 장치 자격증명 방식, broker/저장소/분석기 시험 구성, 부하 도구·목표는 확정되지 않았다.

운영 배포, staging/production 계정·인프라, 과금·렌탈 계약 관리, 외부 임의 장치 연동, 농장 구성원 공유는 현재 필수 개발 범위가 아니다. 로컬 재현에 유용한 CI·컨테이너·관측성은 필요를 확인해 선택할 수 있지만 과거 production 로드맵 전체를 취업 포트폴리오의 완료 조건으로 강제하지 않는다.
